# 盘点差异处理

## 盘点频次

门店执行日清周盘：每天营业结束后对当日动销品类做重点核对，每周固定一天做全品类盘点。月度盘点与财务对账同步进行，盘点结果由店长签字确认后报财务备档。促销档期结束后要加盘一次相关品类。

## 自调范围

盘点差异在 3 件以内（含 3 件）的，按实物数直接调整库存，无需上报。调整后要在盘点表上注明差异原因，常见原因包括破损、丢失、错发、条码串货。同一品类连续两周出现差异的，即使每次都在 3 件以内，也要报店长复核，防止小额差异长期累积。

## 挂起条件

盘点差异超过 3 件的一律挂起，等人工复盘，不要自行调整库存。挂起期间该品类的库存数保持账面值不变，相关补货申请暂停执行，等复盘结论出来后再处理。挂起品类要在盘点系统里标记挂起状态，避免其他店员不知情继续操作。

## 复盘流程

挂起差异的复盘流程：店长牵头核对进货单与销售流水 -> 找出差异原因 -> 出复盘结论 -> 按结论修正库存。复盘结论要在三个工作日内给出，并同步给财务备档。复盘期间允许继续销售，但销售记录要单独留存，供复盘核对。

## 责任认定

复盘确认的差异原因要落到责任：收货验收遗漏的由验收人说明情况，销售漏扫的调当日收银记录核对，内部损耗按门店管理制度处理。责任认定的目的在于改进流程，不搞连带惩罚，但隐瞒不报的从重处理。

## 差异预防

高差异品类要缩短盘点周期，贵重小件商品每日交接班时双清点。收货口的验收流程与销售口的扫码规范是差异预防的两个关键点，新员工上岗前要单独过一遍。系统改库存的权限只开放给店长与盘点负责人，其他岗位只有查询权限。

## 与财务对账

月度盘点的差异汇总表随盘点结果一起报财务，调整库存的凭证要能和盘点表逐条对上。财务抽查时门店要能提供补货单、销售流水与盘点表的完整链路，缺一环的按流程缺陷记录并限期整改。
