# 补货制度

## 适用范围

本制度适用于门店所有在售品类的日常补货，包括仓柜补货、货架直补与供应商直送三种形式。临时性的调拨、借货不属于补货，走调拨单流程。所有补货动作最终都要落到库存账上，没有单据支撑的补货按账实差异处理。

## 报备线

单品单次补货数量超过 50 件的，必须先报备店长审批，审批通过后才能执行补货；50 件以内（含 50 件）的补货，可以直接补到目标库存，无需审批。判断口径是"单次补货数量"，即目标库存减去当前库存的差，不是目标库存本身。拆单规避报备线的，一经发现按违规操作处理。

## 审批链

超线补货的审批链：店员发起 -> 店长审批 -> 执行补货。店长不在时由当班负责人代签，事后一个工作日内补录。审批意见要写明理由，口头同意不算审批。未经审批的超线补货，盘点时按违规操作处理，由发起人承担相应差异责任。

## 补货时点

日常补货在每日盘点结束后统一发起，当日 21 点前提交的补货单当晚处理；周末与节假日等销售高峰前，可提前一至两天发起补货。促销档期的备货单要提前一周报店长确认，防止临时加单压垮收货口。

## 收货与验收

到货后当场验收：核对送货单与实物的品名、规格、数量，破损与临期品当场拒收并在送货单上注明。验收合格才能入库上架，验收人签字确认。先上架后补单的做法不允许，账实时间差控制在当天之内。

## 在途与挂账

已下单未到货的部分记为在途，不占可用库存，也不计入补货数量的判断口径。供应商直送的商品由店长指定专人跟单，到货验收与仓柜补货同一标准。连续两周未到货的在途单要主动催单或取消，避免长期挂账。

## 临期与淘汰

临期商品不再补货，走下架报废流程；保质期剩余三分之一以内的商品要贴临期标并优先陈列。淘汰品类的剩余库存走清仓，不再返单。补货计划里出现淘汰品类的，由店长复核后剔除。

## 记录与追溯

每次补货的发起人、审批人、到货验收人都要留痕，纸面单据当天下班前扫描归档。盘点发现账实差异时，补货记录是追溯的第一手材料，保存期限不少于三个月。
