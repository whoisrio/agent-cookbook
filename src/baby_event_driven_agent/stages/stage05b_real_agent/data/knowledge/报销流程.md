# 报销流程

## 流程总览

报销流程：发起申请 -> 财务审核 -> 打款。所有报销统一走 OA 系统提交，线下票据后补扫描件。报销以公事为前提，私人消费不在报销范围内。一笔报销只填一张申请单，多笔业务分开提交，方便财务按科目审核。

## 交通费

员工因公出行产生的打车费、公共交通费可以报销：在 OA 系统选择"交通报销"，填写事由、日期与金额，上传行程票据。同城出行原则上优先公共交通，打车要写明事由（如携样品上门、夜间收货）。交通费当月发生当月提交，跨月不予受理。

## 差旅报销

异地出差的交通、住宿费按事前审批的差旅单标准报销，超标准部分自理，特殊情况事前报批。住宿发票要开具入住人姓名，行程要与差旅单的日期、城市一致。差旅补贴按天数自动核算，不需要单独贴票。

## 业务招待

招待客户前要先在 OA 里提交招待申请，写明对象、人数与预算，审批通过后实际发生的费用凭发票报销。招待费报销时要附参与人名单，金额超出申请预算百分之十以内的由部门负责人补签确认。

## 办公采购

小额办公用品由门店统一采购分摊，员工个人垫付的应急采购要保留小票，走"办公费用报销"科目，写明品名与用途。单笔超过五百元的采购原则上走对公采购，不受理个人垫付报销。

## 发票要求

报销发票必须是合规发票，抬头、税号正确，开票内容与实际消费一致。电子发票要查验真伪并防止重复报销，同一张发票编号只能提交一次。收据、小票原则上不能替代发票，确无发票的小额费用走备用金说明流程。

## 审核时限

财务审核在收到申请后三个工作日内完成；审核不通过的会退回申请人并注明原因，修改后可重新提交。打款在审核通过后随最近一次发薪日发放，金额较大的报销可向财务申请单独打款。月末最后三个工作日集中对账，建议避开这段时间提交。

## 常见退回原因

被财务退回的常见原因：票据不全、事由不清晰、金额与票据不符、超出标准未附审批、发票抬头错误。退回后请在三个工作日内补正重报，避免跨月失效。对审核结论有异议的，先与财务沟通，沟通不成再走申诉流程。
