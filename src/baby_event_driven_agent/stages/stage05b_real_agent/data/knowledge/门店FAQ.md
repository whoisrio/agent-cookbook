# 门店 FAQ

## 营业相关

门店营业时间为 9:00-21:00，节假日照常营业，春节闭店安排另行通知。开店前做完晨检（卫生、价签、设备），闭店后当日对账。营业时间调整要提前一周公示，并同步更新线上渠道的营业信息。

## 会员与售后

会员积分按实付金额累计，退货时积分同步扣减；积分年底清零前一个月会有双倍积分活动。七天无理由退换以商品完好、配件齐全为前提，食品类商品不支持无理由退货。退款原路退回，现金交易走店长特批的现金退款登记。

## 排班与替班

排班表每周三发布，临时替班要提前一天在排班系统里申请调班，双方店员确认后生效。连续工作超过六天要报店长安排补休。节假日排班按自愿报名加轮换兜底，补贴按人事制度执行。

## 商品陈列

陈列遵循"上轻下重、先进先出"原则，补货时新批次放到货架里侧。促销端架每周一更换，与当期促销档期保持一致。价签与商品一一对应，发现价签错位先按系统价出售并及时反馈核价。

## 促销执行

促销活动的开始与结束以系统生效时间为准，不以店内物料为准；物料提前拆除或滞后下架都要登记。促销商品的库存单独预留，卖完即下架，不允许无货挂促销价。活动结束后三个工作日内交促销复盘，含销量、毛利与库存余量。

## 收银与支付

收银差异当日上报当日处理，不跨日结转；差异超过五十元的要写情况说明。移动支付遇到掉单，先查支付平台流水再决定是否重扫，禁止凭记忆手工改单。发票开具走电子发票，顾客扫码自助填抬头。

## 安全与防损

贵重小件商品每日交接班时双清点，高单价品类放置在视线良好的位置。发现偷盗行为不与对方发生肢体冲突，第一时间按铃通知值班店长处理。消防通道保持畅通，每周检查一次灭火器压力表并留痕。

## 卫生与检查

门店卫生执行区域包干，每日三次巡检（开店、午高峰后、闭店）。生鲜区的清洁记录按班次填写，检查表挂在后场公示。总部飞行检查前会有例行自查，自查发现的问题限期一天内整改。
