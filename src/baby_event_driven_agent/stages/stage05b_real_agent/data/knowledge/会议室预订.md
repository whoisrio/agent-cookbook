# 会议室预订

## 预订流程

会议室预订：需提前一天通过 OA 系统申请，填写事由和时间，经直属上级审批通过后即可生效。预订成功后会收到系统通知，没有收到通知的预订不算生效。临时会议也走系统预订，先到先得，不允许口头占用的做法。

## 时段与时长

单次预订默认以一小时为基本单位，最长不超过四小时；超出四小时的培训类活动要提前三天单独申请。午休时段（12:00-13:30）原则上留给员工休息，确需使用的要注明事由。连续预订同一会议室超过三天的，系统会提示改为固定场地申请。

## 使用规范

会议室按预订时段使用，需要延长要提前在系统里续订；取消预订应提前两小时操作，把时段释放给其他人。会后随手白板擦净、桌椅归位、垃圾带走。两场会议之间预留一刻钟空隙作为会间缓冲，方便下一场使用方布置。

## 设备与故障

会议室的投屏、视频会议设备使用前先测试，投影转接头用完放回原位。设备故障在群里报修并注明会议室与现象，不要自行拆卸挪动。报修后两个工作日未处理的，升级给行政负责人跟进。

## 远程与跨店会议

与远程同事开会优先使用固定视频会议室，提前十分钟到场调试网络与摄像头。跨门店的联席会议由发起人统一预订线上会议号，并通知各参会方会议室安排。外部访客参与的会议要提前报备访客名单，由行政前台对接入园。

## 取消与违约

两次以上预订不使用（爽约）的，系统会暂停该账号的预订权限一周。取消与改期都在系统里操作，改期等于取消后重新预订，时段不保留。节假日前后是爽约高发期，行政会提前清理无人使用的占位预订。
