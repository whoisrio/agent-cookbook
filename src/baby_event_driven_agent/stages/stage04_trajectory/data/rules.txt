会议室预订：需提前一天通过OA系统申请，填写事由和时间，经直属上级审批通过后即可生效。
VPN 申请：内网 portal → 自助服务 → 远程接入，需要部门经理审批。
报销：报销流程：发起申请 -> 财务审核 -> 打款。详见财务制度。
订会议室：会议室预订流程：先在系统中选择会议室和时间 -> 提交申请 -> 管理员确认 -> 使用。
:会议室预订：会议室预订流程：1. 登录系统；2. 选择会议室和日期时间；3. 提交申请；4. 批准即可使用。
补货：单品补货超过 50 件需先报备店长审批，批了才能补；50 件以内直接补到目标库存。
盘点差异：差异 3 件以内按实物数调整库存；超过 3 件挂起，等人工复盘，不要自行调整。
