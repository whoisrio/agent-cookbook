# UI

LangGraph 这套前端库（`@langchain/react`，Vue/Svelte/Angular 都有对应的），说白了就是让你前后端集成的时候，不用自己折腾一套 API 去把图渲染成界面。

你把图跑在 langgraph-api server 上，前端库直接读它吐出来的 EventStream，图里那些节点、状态、中断、检查点，前端直接就能显示、还能交互。本来你得自己干三件事：定义中转接口、手写流式解析、自己管前端状态——现在这套库帮你包了。

不过别误会成不用写代码。图本身的 checkpoint、interrupt 你还是得写；要往前端推业务数据（比如进度、统计）还得写个 StreamTransformer 开自定义通道。它省的是传输层和前端胶水，不是全免。

## 它方便在哪

就说一点：后端引擎有什么概念，前端就有对应的东西能画。

节点不用你在前端写死对应关系。库运行时自己发现有哪些节点，你后端加个节点、调个顺序，前端不用动。

流式输出也不用你自己分。每条消息都标了是哪个节点产出的，直接归到对应卡片就行，不用猜来源。

图里某个状态的字段，前端直接就能拿来用，不用自己解析。

最实用的是中断和恢复。后端一个 interrupt() 停住等人审批，前端直接画个审批卡片，人点一下继续——你不用自己设计这套人机交互的协议。

还有检查点，这个最值钱：前端能回到某一步重新跑，或者从某步拉两条分支对比。别的框架前端根本没这概念。

另外你要推点业务数据（脱敏统计、进度条）给前端，后端写个 StreamTransformer 往命名通道推，前端订阅一下就收到，不用再开个 websocket。

## 几个实打实的经验

走 agent server，别本地 invoke。这套东西前提就是 HTTP API 那一层，本地直接跑接不上。

把 state key 当回事。哪些图的输出要稳定给前端渲染，图定义旁边记清楚，这是前后端的契约。

节点让前端自己发现，别硬编码。条件跳过的节点运行时才出现，你写死了反而留空位。

卡片用节点作用域的消息，别绑死 state key 的名字。

中断恢复直接用 interrupt + Command，前端原生就能画审批，别自己造轮。

业务数据走自定义通道，别往 messages 里塞。进度、指标这些用 StreamTransformer，消息记录干净。

检查点交互这个卖点别浪费。导演审批、重跑某步、对比分支，UI 上全能做——这才是你选 LangGraph 的理由。

框架随便挑，React/Vue/Svelte/Angular 都有对应 hook，别被绑死。

## 啥时候用，啥时候别用

图要实时可视化、要人审批、要能回退调试的界面，这套很合适。

反过来：你后端根本不是 LangGraph 编译的图，协议吃不上；你就想要个简单聊天框，普通聊天 SDK 更轻；你要把一个 agent 塞进交互逻辑完全不同的老产品，官方那套原语反而碍事，不如自己写。

## 非要自己写，得干哪些活

有些场景官方库用不了或者不合适，那就得自己写前后端对接。其实就是把官方库帮你包的那层——传输层加前端胶水——自己重做一遍。具体要支持这些：

得自己定一套流式协议。官方库吃的是 EventStream，你得用 SSE 或者 WebSocket 自己搞一个，每个事件带上类型、属于哪个节点、对应哪个状态键、checkpoint id 这些字段，前端才分得清。

后端得把图的状态机暴露出来。每个节点 pending、running、complete、error 这些状态，既能实时推给前端，也能查。

检查点那套接口最麻烦。官方库直接能 resume、fork，你自己得把 checkpointer 存的每一步快照暴露成接口：列历史 checkpoint、从某步恢复、从某步拉分支。这块是自定义对接里最费劲的。

中断和 resume 也要自己接。节点里能 suspend 等人输入，你还得给个接口让人把输入提交回去、触发图继续跑。

流式 token 归位得前端自己干。每个 chunk 带上节点名推过来，前端按这个字段分流到对应卡片，没人帮你自动路由。

业务数据（进度、统计）要么塞进同一套事件协议，要么你再开个通道。

前端那堆活也得自己写：节点和 UI 的对应关系你硬编码，作用域消息、审批卡、checkpoint 列表界面，全得从零来。

一句话，自己写不神秘，就是把官方库省掉的那两层重做。难点集中在检查点和中断的接口设计——这两块搞定了，其余就是体力活。

> 包名别写错：现在官方 React 包是 `@langchain/react`（旧名 `@langchain/langgraph-sdk/react`），没有 `@langgraph/react` 这东西。Vue/Svelte/Angular 对应 `@langchain/vue`、`@langchain/svelte`、`@langchain/angular`。
